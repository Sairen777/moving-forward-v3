# Background System

The animated ASCII field is a generated, profile-driven DOM background rendered as fixed-position rows from a single base buffer. The client mutates dirty-row `innerHTML` after a 2000 ms delay; SSR emits the static base so first paint and hydration are pixel-identical.

## Architecture

```
src/backgrounds/
  types.ts              — AsciiBackgroundProfile shape contract
  current.ts            — active profile + generated CSS seam
  quiet-field/
    profile.ts          — generated: meta, data, render, timing, motion
    background.module.css — generated: .bg, .row, span, and per-color rules

src/components/
  SiteBackground.tsx    — SSR row map + client dirty-row animation

src/lib/
  ascii-background-dom.ts — decode, row HTML, motion state, frame writes

tools/
  asciify.py            — generator: python3 tools/asciify.py field 120
```

## How it works

1. **SSR.** `SiteBackground` renders a `<div data-ascii-background-root>` containing 61 `<div data-ascii-row>` elements. Each row's `innerHTML` is precomputed from the static base buffer at module scope. `<NoHydration>` leaves the row subtree untouched during client hydration, so the same DOM that SSR emitted stays on screen.

2. **Client animation.** On mount, `buildAsciiMotionState` precomputes per-column lift, gain, phase, and mirror indices from the immutable base bytes. A `motionIndexes` array includes only cells where both lift and gain are non-zero, so the frame loop only visits wheat columns.

3. **Delay and dirty-row update.** The animation waits `background.timing.startDelayMs` (2000 ms on the home route). After the delay, a `requestAnimationFrame` loop runs every `background.timing.frameMs`. Each accepted frame calls `writeAsciiFrame` to sample wind-displaced glyphs from the immutable base into the `next` buffer, then compares against the `previous` buffer to find dirty rows. Only dirty rows get `innerHTML = renderAsciiRow(...)` — the rest stay untouched.

4. **Static routes and reduced motion.** When the route changes from home to an article, the animation pauses on the current visible frame — DOM rows stay as-is, buffers and elapsed time are preserved. Navigating back home resumes from that held elapsed time without replaying the start delay. Direct article loads show the static SSR base rows. When `prefers-reduced-motion: reduce` matches, every row resets to the base HTML and stays static. No backend, `localStorage`, or `sessionStorage` is used for route-continuity behavior.

## Generating a background

```bash
pnpm field
```

This runs `tools/asciify.py field 120` and writes:

- `src/backgrounds/quiet-field/profile.ts`
- `src/backgrounds/quiet-field/background.module.css`

The generator uses the source image at `tools/0x1900-000000-80-0-0.jpg` (120 source columns, mirrored to 240). To change the source image or generation parameters, edit `tools/asciify.py`.

The generated files carry a `/* Generated by tools/asciify.py field; do not edit by hand. */` header and are excluded from Biome formatting.

## Profile shape

The `AsciiBackgroundProfile` type in `src/backgrounds/types.ts` is the contract. Every background profile must provide:

- **meta** — grid dimensions, color palette, glyph ramp, source attribution
- **data** — base64-encoded byte field (one byte per cell: low nibble = glyph index, high nibble = color class)
- **render** — font stack, cell aspect ratio, horizontal tile repeats
- **timing** — animation start delay, frame interval, motion ramp duration
- **motion** — bend, arc, wave parameters for the wind simulation

`render.tileRepeats` controls how many times the 240-column source tiles horizontally. The default is 3, covering aspect ratios up to 32:9 without viewport-dependent HTML.

## Swapping backgrounds

Change **one file**: `src/backgrounds/current.ts`.

```ts
// Example: switch to a new "storm-field" background
import backgroundStyles from "./storm-field/background.module.css";
import { stormFieldBackground } from "./storm-field/profile";

export const activeBackground = stormFieldBackground;
export const activeBackgroundMeta = activeBackground.meta;
export const activeBackgroundStyles = backgroundStyles;
```

The rest of the site reads from `activeBackground`, `activeBackgroundMeta`, and `activeBackgroundStyles` — no other files change.
