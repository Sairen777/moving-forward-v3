## Anti-Patterns Verdict

**LLM assessment:** Does not read as AI-generated. The dominant identity (generated ASCII wheat field + monospace manifest) is bespoke and unmistakable. The serif body is a reading-comfort choice, not a display affectation: headings, title, and masthead stay monospace, so the page does NOT match the saturated "editorial-typographic" reflex lane (italic display serif + mono labels + no imagery). The wheat field is the imagery. The chosen serif (Iowan Old Style / Palatino / Charter / Georgia) is off the reflex-reject font list.

**Deterministic scan (detect.mjs):** `index.html` -> `single-font` (warning) and `numbered-section-markers` (advisory). Both known false positives: single-font is the intentional one-family chrome rule; the "numbered markers" match incidental ISO-date digits (2024.11.18), not section scaffolding (the Manifest-Index Rule keys on the date). `post.html` -> clean. The serif body resolves the single-font warning the detector raises against pure-mono pages, corroborating the change as an improvement.

## What's Working
1. Reading comfort: serif body (18px / 1.7, ~66ch) + near-opaque feathered halo + frozen field directly serve PRODUCT.md Principle 3 ("Words first") and resolve the complaint that monospace was hard to read.
2. The fade is not a new idiom: it is the documented paper-wash/veil extended (a gradient that reveals the background is atmosphere, not elevation), so it deepens the system rather than fighting the flat / no-shadow rules.
3. Mono chrome + serif body yields code-vs-prose contrast (code now reads as code) and keeps the generated-manifest identity at the masthead.

## Priority Issues
- **[P1] Mode split was undocumented (consistency).** Resolved this pass: DESIGN.md sections 3/4/5/6 and the sidecar now codify the Mono-Chrome / Serif-Reading Rule, the Paper-Wash Rule, the Article Reading View component, and the field freeze-on-reading behavior.
- **[P2] Index/article field-treatment divergence.** Resolved this pass: the index reading sheet now uses the same feathered paper-wash (at 90%, field-forward), so the Paper-Wash Rule holds site-wide. The index keeps its animated field and all-mono manifest by intent.
- **[P2] Editorial-typographic adjacency risk.** Mitigation documented as a Don't: article headings, title, and masthead stay mono; never an italic display serif or drop caps.
- **[P3] Frozen field vs "motion as weather."** Ratified: reading pages hold still (reading comfort wins); the index keeps the weather. Documented; slow-drift remains an option.

## Minor Observations
- Sub-1000px: the halo yields to a solid sheet (no room to feather); text stays fully opaque.
- Mobile: no page overflow; the code block scrolls internally.
- Short prose on the index (lede, About) stays monospace by intent; serif is reserved for long-form article bodies.
